# HR-Attrition-Analysis
Python-based HR Attrition Analysis using Pandas, NumPy, Matplotlib, and Seaborn to identify employee attrition patterns, analyze key factors, and generate data-driven HR retention insights.

## Project Overview
This project analyzes employee attrition patterns using Python to identify factors associated with employee turnover and provide data-driven insights for HR retention strategies.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Work
- Explored employee data and checked data quality.
- Analyzed attrition by overtime, income group, work-life balance, and department.
- Investigated relationships between employee characteristics and attrition.
- Created visualizations to communicate key findings.
- Developed recommendations to support employee retention.

## Key Findings
- Overall employee attrition rate: 16.12%.
- Attrition was higher among employees working overtime (30.53%) than those not working overtime (10.44%).
- The low-income group had a 29.27% attrition rate, compared with 10.33% for the high-income group.
- Employees with a work-life balance rating of 1 had the highest attrition rate (31.25%).

## Project Files
- `Hr_Attrition_Project.ipynb` — Python analysis and visualizations.
- `HR_Attrition_Report.pdf` — Project report, findings, and recommendations.

## Conclusion
The analysis identifies employee groups and workplace factors associated with higher attrition. These findings can help guide further investigation into employee retention. The results show associations, not proof of causation.
